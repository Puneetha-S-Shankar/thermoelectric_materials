### V4 Data preprcoessing 


| Issue | Impact on Model | Preprocessing Technique | Outcome |
|------|----------------|------------------------|--------|
| Scale imbalance across targets | Training instability, poor convergence | Log₁₀ transformation | Normalized output ranges |
| Negative target values | Invalid for log transformation | Absolute value conversion | Physically meaningful magnitude retained |
| Zero values in targets | Undefined logarithm | Additive shift (+1) before log | Numerical stability ensured |
| Extreme feature outliers | Model bias toward rare values | IQR-based clipping (3×IQR) | Robust feature distribution |
| Missing feature data | Loss of training samples | Median imputation | Dataset size preserved (~24k samples) |



### Model Architecture

Used Feed forward neural network with ReLU. he model uses a multi-layer neural network with normalization, dropout, and robust scaling to learn complex, shared representations of material properties for accurate multi-target prediction.

- **Input:** 13 features  

- **Hidden Layers:**
  - Dense(128)
  - Dense(64)
  - Dense(32)

- **Output Layer:**
  - 3 neurons (multi-target prediction)

- **Additional Components:**
  - Batch Normalization → stabilizes training  
  - Dropout → prevents overfitting  

- **Total Parameters:** ~12,000

## 5.3 Key Techniques

### 🔹 ReLU Activation
- Formula: `ReLU(x) = max(0, x)`
- Enables learning of non-linear relationships  

---

### 🔹 Batch Normalization
- Normalizes layer outputs during training  
- Benefits:
  - Faster convergence  
  - Stable training  
  - Better generalization  

---

### 🔹 Dropout
- Randomly disables neurons during training  
- Prevents overfitting  

- Configuration:
  - Layer 1 → 30%  
  - Layer 2 → 20%  
  - Layer 3 → 10%  

---

### 🔹 Multi-Output Learning
- Single model predicts all 3 targets  

- Advantages:
  - Shared feature learning  
  - Improved efficiency  
  - Better generalization  

---

### 🔹 RobustScaler
- Scales data using median and IQR  
- Less sensitive to outliers compared to standard scaling
